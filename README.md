# Gothic Co-op Escape Room

A 2D local cooperative puzzle escape game developed
in Unity as part of a Game Design course at Aalborg
University (AAU).

## Project Overview

Players take on the roles of a Nurse and a Vampire,
combining their unique abilities to solve puzzles,
uncover secrets, and complete an ancient ritual.

The game combines gothic aesthetics, environmental
storytelling, original pixel art, and asymmetric
cooperative gameplay.

## Technologies & Tools

- Unity
- C#
- Unity Input System
- Aseprite
- Visual Studio
- Git & GitHub
- Miro

## Key Features

- Local two-player cooperative gameplay
- Asymmetric character abilities
- Interactive environmental puzzles
- Item pickup, usage, and inventory interactions
- Puzzle progression and event management
- Character animations and dialogue systems
- Original pixel art, tilesets, and visual assets
- Sound design and audio integration
- Environmental storytelling

## Game Design & Development

The game was developed using an iterative,
playcentric design approach inspired by Tracy
Fullerton's Game Design Workshop.

The development process included:

- Concept development and brainstorming
- Physical prototyping
- Level design and greyboxing
- Digital prototyping
- Iterative playtesting and refinement
- Gameplay balancing and visual polish

Playtesting informed both technical and design
decisions, including the introduction of emergent
gameplay features based on player behavior.


## Academic Context

Developed as part of the Game Design course
at Aalborg University, Denmark.
